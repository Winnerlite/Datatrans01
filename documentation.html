Base URL

https://www.intercityprices.com.ng/api

HTTPS only. HTTP requests are rejected.

Authentication

🔑 API Key Required

Every request must include your API key in the x-api-key header. Contact us to receive a key.

Header Format

x-api-key: vyra_live_yourkey_xxxxxxxxxx

Complete Example

curl -H "x-api-key: vyra_live_yourkey_xxxxxxxxxx" \
"https://www.intercityprices.com.ng/api/search?q=Lagos"

What Happens Without a Key

Scenario Response
No x-api-key header 401 Missing API key
Invalid or revoked key 403 Invalid or revoked API key
Valid key 200 Success

Getting a Key

API keys are issued per client. Email vyraintercitymetrics@gmail.com with your company name and use case. Once approved, you'll receive a key to include in every request.

Testing without a key: use our hosted Live API Tester to explore endpoints and responses before requesting a key.

Endpoints

GET /api/search

Search by state name, company name, or route keyword. Returns matching states, companies, and routes.

Query Parameters

Name Type Required Description
q string Yes State, company, or route fragment
attribute string No Filter by service attribute (Comfort, Safety, Quick, etc.)

Example Request

GET /api/search?q=Lagos

Example Response

{
  "query": "lagos",
  "results": {
    "states": [
      {
        "name": "Lagos",
        "companies": ["ABC Transport", "God is Good Motors", "GUO Transport"],
        "majorTerminals": [
          {
            "name": "Jibowu Terminal",
            "address": "22, Ikorodu Road, Jibowu, Yaba, Lagos",
            "phone": "08139862090"
          }
        ]
      }
    ],
    "companies": [],
    "routes": [
      {
        "route": "Lagos-Onitsha",
        "prices": {
          "ABC Transport": 29120,
          "GUO Transport": 35490,
          "Peace Mass Transit": 22750
        }
      }
    ]
  },
  "totalFound": 12
}
GET /api/transport

Returns the complete dataset — all companies, terminals, states, and direct route prices in a single JSON payload. Best for caching locally.

Query Parameters (Optional)

Name Type Description
state string Filter to a single state
company string Filter to a single company

Example Response (trimmed)

{
  "transportCompanies": {
    "ABC Transport": {
      "id": "abc-transport",
      "name": "ABC Transport Plc",
      "basePrice": 23904,
      "states": ["Lagos", "Abuja", "Rivers"],
      "terminals": { "Lagos": [...] }
    }
  },
  "states": {
    "Lagos": { "companies": ["ABC Transport", "God is Good Motors"] }
  },
  "routePrices": {
    "Lagos-Onitsha": { "ABC Transport": 29120, "GUO Transport": 35490 }
  }
}
Recommended: fetch this once at startup, cache in memory or localStorage, refresh hourly.
GET /api/states

Returns all states with their active transport operators, or a single state if filtered.

Query Parameters (Optional)

Name Type Description
state string Return only this state's data

Example Response

{
  "Lagos": {
    "companies": ["ABC Transport", "God is Good Motors", "GUO Transport"],
    "majorTerminals": [...]
  },
  "Abuja": {
    "companies": ["ABC Transport", "Chisco Transport"],
    "majorTerminals": [...]
  }
}
GET /api/companies

Returns all transport companies, or one company if filtered.

Query Parameters (Optional)

Name Type Description
company or name string Return only this company
GET /api/routes

Returns route prices between states — all routes, or one route if filtered.

Query Parameters (Optional)

Name Type Description
route string Full route key (e.g., Lagos-Abuja)
from + to string Origin and destination (e.g., ?from=Lagos&to=Abuja)

Example Response

{
  "route": "Lagos-Abuja",
  "from": "Lagos",
  "to": "Abuja",
  "prices": {
    "ABC Transport": 31850,
    "God is Good Motors": 56900,
    "GUO Transport": 30030,
    "Chisco Transport": 31850,
    "Peace Mass Transit": 25480
  }
}

Code Examples

JavaScript (fetch)

const res = await fetch(
  'https://www.intercityprices.com.ng/api/search?q=Lagos',
  {
    headers: { 'x-api-key': 'vyra_live_yourkey_xxxxxxxxxx' }
  }
);
const data = await res.json();

data.results.states.forEach(state => {
  console.log(state.name, '→', state.companies.length, 'companies');
});

Python (requests)

import requests

response = requests.get(
    "https://www.intercityprices.com.ng/api/search",
    params={"q": "Lagos"},
    headers={"x-api-key": "vyra_live_yourkey_xxxxxxxxxx"},
    timeout=10
)
response.raise_for_status()
for state in response.json()["results"]["states"]:
    print(state["name"], "→", len(state["companies"]), "companies")
